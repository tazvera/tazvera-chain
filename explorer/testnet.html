How to join the testnet

टेस्टनेट से कैसे जुड़ें

Public Explorer & RPC endpoints opening soon
पब्लिक एक्सप्लोरर और RPC जल्द ही उपलब्ध होंगे
01

Build the node

नोड बनाइए

Clone the repository and build taznode from source with CMake. No prebuilt release is published yet.

रिपॉज़िटरी क्लोन कीजिए और CMake से taznode खुद बनाइए। अभी कोई तैयार रिलीज़ जारी नहीं हुई है।

02

Load Genesis Config

जेनेसिस कॉन्फ़िगरेशन लोड करें

Point your node configuration to the sample genesis commitment hash and configure peer discovery.

अपने नोड कॉन्फ़िगरेशन को सैंपल जेनेसिस कमिटमेंट हैश से जोड़ें और पीयर डिस्कवरी सेट करें।

03

Sync & Verify Records

सिंक करें और रिकॉर्ड जांचें

Start the node daemon to sync blocks locally and test submitting sample on-chain asset records.

लोकल स्तर पर ब्लॉक सिंक करने के लिए नोड शुरू करें और सैंपल ऑन-चेन एसेट रिकॉर्ड सबमिट करके देखें।

NOTICE चेतावनी

Experimental Prototype Environment

प्रायोगिक प्रोटोटाइप वातावरण (Experimental Prototype)

This network is an early-stage experimental prototype. It involves no real money or financial value, operates without TLS encryption, and contains no payment path. Do not transmit sensitive data or real assets.

यह नेटवर्क एक शुरुआती प्रायोगिक प्रोटोटाइप है। इसमें कोई वास्तविक पैसा या वित्तीय मूल्य शामिल नहीं है, यह बिना TLS एन्क्रिप्शन के चलता है, और इसमें कोई पेमेंट पाथ नहीं है। कृपया कोई भी संवेदनशील डेटा या असली संपत्ति न भेजें।
