TAZVERA Chain — v8.3 (Windows fix + genesis pin)
================================================

इस फ़ोल्डर में आपके प्रोजेक्ट का पूरा, अपडेटेड कोड है। इसमें तीनों सुधार पहले से
डाले हुए हैं — कोई "patch" लगाने की ज़रूरत नहीं है।

क्या बदला है (सिर्फ़ 5 फ़ाइलें):
  1. .gitattributes
  2. src/persist.cpp
  3. include/taz/persist.hpp
  4. tests/test_persist.cpp
  5. tests/test_security82.cpp

तीन सुधार:
  (क) Windows पर फ़ाइल बदलते समय retry — जिससे "ok == 60" वाला test fail नहीं होगा।
  (ख) .gitattributes में eol=lf — जिससे Windows पर JSON फ़ाइलों की line endings
      नहीं बदलेंगी और "slurp == to_json" वाला test पास होगा।
  (ग) genesis pin — LoadOptions::expected_genesis_commitment, अपने test के साथ।


GitHub पर कैसे डालें (आसान तरीक़ा)
----------------------------------
1. इस zip को खोलिए। अंदर एक फ़ोल्डर मिलेगा: tazvera-chain
2. ब्राउज़र में अपना रेपो खोलिए: github.com/tazvera/tazvera-chain
3. ऊपर "Add file" → "Upload files" पर क्लिक कीजिए।
4. अब tazvera-chain फ़ोल्डर के अंदर जो चीज़ें हैं (src, tests, include, explorer,
   .github फ़ोल्डर और बाक़ी सारी फ़ाइलें) उन्हें चुनकर उस पेज पर खींच दीजिए।
   - पूरा फ़ोल्डर एक साथ खींच सकते हैं, या अंदर की सारी चीज़ें चुनकर खींचिए।
   - ध्यान रखिए: फ़ोल्डर के अंदर की चीज़ें खींचिए, tazvera-chain फ़ोल्डर खुद नहीं।
5. नीचे "Commit changes" दबाइए (main branch पर)।
6. commit होते ही GitHub Actions अपने आप चलेंगे — "C++ Core CI" और
   "Windows (experimental)". दोनों हरे होने चाहिए।

अगर पूरा फ़ोल्डर डालना मुश्किल लगे
----------------------------------
तो सिर्फ़ ऊपर लिखी 5 फ़ाइलें एक-एक करके बदल दीजिए:
  - GitHub पर उसी फ़ाइल को खोलिए → पेंसिल (Edit) → सारा पुराना टेक्स्ट हटाइए →
    इस फ़ोल्डर की उसी फ़ाइल का टेक्स्ट पेस्ट कीजिए → "Commit changes".
  - tests/test_security82.cpp नई फ़ाइल नहीं है, वह पहले से रेपो में है, उसे भी
    इसी तरह बदल दीजिए।

ज़रूरी बातें
------------
- zip फ़ाइल को खुद रेपो में अपलोड मत कीजिए; सिर्फ़ उसके अंदर का कोड डालिए।
- यह कोड मेरी तरफ़ से compile नहीं हुआ है (मेरे पास C++ compiler नहीं है),
  इसलिए असली जाँच GitHub Actions ही करेगा।
- अगर कोई test लाल आए, तो उसका पूरा message मुझे भेज दीजिए, मैं ठीक कर दूँगा।
